## 今日趋势观察

1. Agent workflow 基础设施继续升温：repo-local graph/spec/memory、模型团队编排、agent web access、governed runtime 都在解决“agent 如何带状态、带证据、带约束地工作”。
2. MCP 正从“接入工具”继续走向“压缩、治理、领域化”：BioNexus、OpenReach、DSH plugins 和 donation MCP 分别代表科学工具、Web 访问、UI 表达和支付动作的协议化。
3. Local-first 叙事更强调边界：Codify 的本地 SQLite、kenward 的家庭/个人记忆隔离、Epiq 的 append-only evidence、image-workbench 的本地画布和文件，都把持久状态放到产品核心。
4. 浏览器/自动化平台今天更像 agent substrate，而不是终端产品：Bun automation platform 有 API/queue/screenshot 基础，但还需要明确 agent safety 与 auth。
5. 高风险动作需要降权：支付、物理刺激、机器人/硬件和生产基础设施改动类项目，除非 README 和代码中有强授权/确认/回滚设计，否则不进入 Top。
