## Trend Observations

1. WebMCP is becoming a product primitive: folder workspaces, storefronts, recovery admin, hardware diagnostics, analytics studios, and browser repair loops all expose typed tools from the page state rather than asking agents to scrape UI.
2. Human sovereignty is a repeated differentiator: checkout gates, physical actuation approval, browser handoff, repair publishing approval, and local-file privacy all treat consequential action as a separate product state.
3. Coding-agent infrastructure is moving from prompts to operating systems: visual graphs, worktree isolation, session migration, browser/session CLI, and office/desk metaphors are converging around controllable agent workspaces.
4. Runnability signals are strongest when repos include tests, Docker, smoke commands, demo GIFs/screenshots, and explicit no-key mock modes. Star count is still weak for very fresh projects.
5. The highest-signal projects today are not generic chat assistants; they make an agent interact with a browser, file system, hardware lab, job funnel, or engineering workflow through an explicit tool/action contract.
