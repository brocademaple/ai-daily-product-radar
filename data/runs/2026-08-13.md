## 今日趋势观察

1. Agent control plane 正在从单一 IDE 插件扩展到远程会话、手机/PWA 控制、agent multiplexer、inter-agent handoff 和可审计 receipt。
2. MCP 的产品化重点从“再做一个 server”转向 gateway、registry、repo-context pack、permission/audit 和隐私边界。
3. Coding-agent 周边的好项目越来越具体：image context runtime、markdown coordination、local desktop shells、proof receipts、assumption measurement，比泛泛的 code chatbot 更有产品面。
4. 垂直 agent 候选开始把 API login、workflow、memory、监督 UI 和资料处理打包到一个场景中，YYGlobal、fantasybot、SponsorFit、Nautilus Studio 都在这个方向。
5. 同期出现大量 Agent Skills、prompt contracts、awesome lists 和 provenance tools；它们是生态信号，但大多不应挤占可运行产品 Top 位。
